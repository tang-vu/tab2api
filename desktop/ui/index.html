Authentication

Only healthz is public. Every other route requires a revocable tab2api bearer key; administrator routes require the original administrator key. 

Authorization: Bearer <tab2api-key>

Quick start

Replace the placeholder key, then send an OpenAI-shaped Chat Completions request. 

curl.exe http://127.0.0.1:3210/v1/chat/completions `
  -H "Authorization: Bearer <tab2api-key>" `
  -H "Content-Type: application/json" `
  -d '{"model":"chatgpt-web","messages":[{"role":"user","content":"Hello"}]}'
{
  "id": "chatcmpl_...",
  "object": "chat.completion",
  "model": "chatgpt-web",
  "choices": [{
    "index": 0,
    "message": { "role": "assistant", "content": "Hello!", "refusal": null },
    "logprobs": null,
    "finish_reason": "stop"
  }],
  "usage": { "prompt_tokens": 0, "completion_tokens": 0, "total_tokens": 0 },
  "tab2api": { "usage_available": false, "stream_mode": "buffered" }
}

Projects and persistent sources

Create or list projects, upload source files once, and continue project-scoped conversations with conversation_id.

POST/v1/projectsBearer key
GET/v1/projectsBearer key
DELETE/v1/projects/:projectIdBearer + confirmation
POST/v1/projects/:projectId/filesmultipart/form-data
POST/v1/projects/:projectId/chat/completionsJSON
POST/v1/projects/:projectId/responsesJSON
Irreversible deletion DELETE also requires X-Tab2api-Confirm-Delete to exactly equal the project ID.

Image and audio

Image generation and transcription use the public ChatGPT UI. Speech uses the local operating-system voice and returns WAV only.

POST/v1/images/generationsJSON · PNG base64
POST/v1/audio/transcriptionsmultipart/form-data
POST/v1/audio/speechJSON · audio/wav

Administrator endpoints

Manage revocable client keys, inspect content-free usage counters, or reset the browser session. These routes reject client keys.

DELETE/admin/api-keys/:idAdministrator key
GET/admin/usageAdministrator key
DELETE/admin/usageAdministrator key

Limits and behavior

Requests enter a bounded FIFO queue. Streaming is buffered, UI selectors may change, and token counts are unknown estimates—not billing data.

Enable bearer-only tunnel?

Bearer-only makes the hostname publicly reachable. Continue only for one owner, with an independent revocable tab2api client key. Cloudflare Access is safer. Enable bearer-only mode?
