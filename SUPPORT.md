# Support

tab2api is an early, unofficial single-user browser automation project. Community support is best-effort; no uptime, compatibility, or response-time guarantee is provided.

## Before opening an issue

1. Read the [README](README.md), [troubleshooting guide](docs/troubleshooting.md), and [security policy](SECURITY.md).
2. Run `npm run doctor` and reproduce with the latest release or current `main`.
3. Remove credentials, tokens, cookies, browser/profile data, prompts, responses, account identifiers, hostnames, local paths, HAR files, traces, and unsanitized screenshots from your report.
4. Use the matching GitHub issue form and include only a minimal sanitized reproduction.

Questions or requests for shared hosting, account rotation, private ChatGPT endpoints, challenge bypass, stealth, fingerprint manipulation, quota circumvention, or credential extraction are unsupported.

Report vulnerabilities only through the private process in [SECURITY.md](SECURITY.md), never through a public support issue.
